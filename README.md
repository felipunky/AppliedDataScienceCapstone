# Applied Data Science Capstone

Welcome to the **Applied Data Science Capstone** repository! This project forms part of the **IBM Data Science Professional Certificate**, focusing on applying data science methodologies to analyze, visualize, and predict real-world outcomes.

---

## 📌 Project Overview

The goal of this project is to apply end-to-end data science methodologies—including data collection, exploratory data analysis (EDA), predictive modeling, and interactive visual analytics—to address complex data-driven problems.

---

## 🛠️ Repository Structure & Key Modules

- **`Introduction/`**: Overview of the project, problem definition, and initial data collection strategy.
- **`ExploratoryDataAnalysis/`**: EDA using SQL queries and Python visual libraries (Matplotlib, Seaborn) to discover insights and relationships within the dataset.
- **`InteractiveVisualAnalyticsAndDashboard/`**: Geospatial interactive mapping and dynamic dashboards. Access the live web app here:
  - 🔗 **[Interactive Visual Analytics and Dashboard](https://felipegutie1-8050.theiadockernext-0-labs-prod-theiak8s-4-tor01.proxy.cognitiveclass.ai/)**
- **`PredictiveAnalysis/`**: Machine learning classification models (Logistic Regression, Decision Trees, SVM, Random Forest), hyperparameter tuning, and evaluation.
